## What's new this week

### antcrew v0.35.0 — antcrew_engine bundled, single install

`antcrew_engine` is now shipped inside the `antcrew` wheel. One install gets everything:

```bash
pip install antcrew   # antcrew_engine included — no separate install needed
```

All existing imports continue to work unchanged:

```python
from antcrew_engine import EngineLoop, MemoryStore, Goal   # still works
from antcrew.engine import EngineLoop                       # also works
```

**Migration:** remove `antcrew-engine` from your `requirements.txt` or `pyproject.toml`. The `antcrew-engine` package on PyPI (v0.4.0) is now a stub that depends on `antcrew>=0.35` — existing pins still install correctly.

**Why:** one install, one version, zero dependency conflicts. Future development of the engine happens in [github.com/iagop03/antcrew](https://github.com/iagop03/antcrew). The antcrew-engine GitHub repo is archived.

### antcrew run --compliance — one-flag audit trail

New flag on `antcrew run` that enables compliance mode for any pipeline run:

```bash
antcrew run "Review this NDA" --team LegalReviewTeam --compliance
```

Effects:

- Forces **full TraceLog** — every prompt and response is recorded, not just token counts
- Auto-creates a timestamped `.db` file if `--trace` is not specified
- Writes a `compliance_<run_id>.json` attestation after the run:

```json
{
  "run_id": "abc123",
  "attested_at": "2026-08-22T14:05:00Z",
  "team": "LegalReviewTeam",
  "model": "claude-sonnet-5",
  "governance_hash": "sha256:a1b2c3d4e5f6789a",
  "cost_usd": 0.43,
  "duration_s": 12.7,
  "full_trace": true,
  "trace_db": "compliance_20260822_140500.db"
}
```

Designed for healthcare, fintech, and legaltech audit pipelines. Pairs with `antcrew inspect <run-id>` for full per-agent trace review.

See [Compliance Pack](../platform/compliance-pack.md) for the full audit workflow.

### keybridge v2.2.0 — renamed from antcrew-proxy

The proxy package is renamed to **keybridge**. All references to `antcrew-proxy` in documentation, Docker images, and platform code have been updated.

```bash
pip install keybridge
# or
docker pull ghcr.io/iagop03/keybridge:latest
```

The old `antcrew-proxy` name on PyPI will not receive further updates. The Docker image `ghcr.io/iagop03/antcrew-proxy` continues to work but is deprecated — update your Compose files to use `ghcr.io/iagop03/keybridge:latest`.

**Why the rename:** "keybridge" is a more descriptive name — it bridges LLM API keys between your infrastructure and the providers, keeping them off antcrew-platform. The shorter name also makes CLI help and log lines easier to read.

### Local-first documentation rewrite

The main README and docs site have been rewritten to lead with the local-first experience:

- `pip install antcrew` → run with `--model simulated` (zero setup) → `--model ollama:llama3` (local AI) → cloud key (real AI with billing)
- SimulatedLLM is now explicitly documented as a deterministic test stub — not real AI output
- antcrew-platform is positioned as the optional cloud layer, not a prerequisite
- antcrew-engine is no longer surfaced as a separate install in any user-facing doc

## Upgrading

```bash
pip install --upgrade antcrew keybridge
```

Remove `antcrew-engine` from your dependencies — it is now bundled with antcrew.

For antcrew-platform self-hosters: no schema migration this week. Pull the latest image and restart.
