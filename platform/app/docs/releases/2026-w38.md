## What's new this week

### antcrew v0.36.0 — Legacy / COBOL support

This release adds first-class support for IBM AS/400 (iSeries) organisations running COBOL. The goal is to let teams add AI to their COBOL estate without rewriting anything.

```bash
pip install "antcrew[docs,legacy]"
```

#### COBOL documentation indexing

`.cbl`, `.cob`, `.cpy`, and `.copy` files are now first-class citizens in the documentation module. Point `--docs-dir` at a directory that contains COBOL source and they are parsed, indexed, and made available for semantic search and agent context injection — the same as Markdown or Word files.

The `CobolParser` handles fixed-format (sequence numbers in cols 1-6, indicator at col 7) and free-format COBOL. It extracts program structure, data items with PIC clauses, paragraph names, and COPY/CALL statements into a human-readable summary that the LLM can work with.

Set `org_type: legacy` in your schema to unlock COBOL-aware routing:

```yaml
documentation_schema:
  org_type: legacy
  if_legacy:
    cobol_support:
      copybook_parsing: true
      batch_job_docs: true
```

#### AS400Connector

New read-only connector to IBM DB2 for i (AS/400) databases via ODBC:

```python
from antcrew.integrations.as400 import AS400Connector

with AS400Connector(dsn="MY_AS400_DSN", username="U", password="P") as conn:
    schema = conn.get_schema("ORDLIB.ORDHDRF")
    print(conn.get_copybook("ORDLIB.ORDHDRF"))   # COBOL FD layout
    rows = conn.sample_data("ORDLIB.ORDHDRF", limit=10)
```

Requires `pip install antcrew[legacy]` (adds `pyodbc>=4.0.35` and the IBM iSeries Access ODBC driver).

#### antcrew augment-cobol

New CLI command that adds AI to a COBOL program without replacing it:

```bash
antcrew augment-cobol ORDPRC.cbl \
  --requirement "Add ML fraud scoring to order processing" \
  --model claude-sonnet-5
```

Produces three files:

- `ordprc_ai.py` — Python class with AI enrichment hooks and a COBOL bridge stub
- `ordprc_ai_caller.cbl` — COBOL bridge program (`ORDPRCAI`) that calls the Python service
- `ordprc_deployment_guide.md` — integration instructions for REST adapter, IBM MQ, and batch file exchange

When `--model` is omitted a well-structured static template is generated. Pair with `--dry-run` to preview without writing files.

```python
# Python API
from antcrew.augment.cobol import COBOLAugment

result = COBOLAugment(llm=my_llm).augment("ORDPRC.cbl", "Add fraud scoring")
print(result.python_wrapper)
print(result.deployment_guide)
```

### polytranslate — new repository

[github.com/iagop03/polytranslate](https://github.com/iagop03/polytranslate) is a new standalone library for full COBOL → Python / Java / Go structural translation.

```bash
pip install polytranslate
```

```python
from polytranslate.languages.cobol import CobolParser
from polytranslate.targets.python import PythonGenerator

ast = CobolParser().parse_file("ORDPRC.cbl")
for f in PythonGenerator().generate(ast):
    f.write("./output")
# ordprc_model.py  — dataclasses for WORKING-STORAGE / LINKAGE
# ordprc_logic.py  — each COBOL paragraph → a Python method
# ordprc_runner.py — entry point
```

The translation is structural: every data item and paragraph is mapped, producing a working skeleton for developer review. It does not simulate COBOL runtime behaviour.

Java and Go generators are stubs this week — contributions welcome.
