Methodology

Task benchmarks run with SimulatedLLM in CI for deterministic results, and with real provider models for cost/token numbers. Pass rate = fraction of runs that produced all expected output keys without errors. Duration is wall-clock seconds from pipeline.start to pipeline.end. Framework comparison values are sourced from published benchmarks and reflect typical production configurations — actual results vary by task complexity and model selection.
